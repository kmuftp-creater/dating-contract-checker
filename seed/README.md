# 初始法規資料

這個目錄放的是系統首次啟動時要匯入資料庫的兩份官方文件，匯入後成為「第 1 版」的生效版本。之後的更新一律在後台的「法規文件」頁面貼上新內容，不要改這裡的檔案。

| 檔案 | 內容 | 在系統中的角色 |
|---|---|---|
| `checklist.md` | 115 年交友媒合服務定型化契約查核表 | 檢核的主清單。AI 逐項判定，一列對應一個查核項目 |
| `regulation.md` | 交友媒合服務定型化契約應記載及不得記載事項（公告全文） | 檢核的引用來源。AI 在改善方式中引用條文原文與點次 |
| `checklist.docx` | 查核表的官方原檔 | 供前台下載 |
| `regulation.pdf` | 公告的官方原檔 | 供前台下載 |

## 來源

內政部 115 年 5 月 8 日台內戶字第 1150114590 號公告，自 115 年 9 月 1 日生效。

兩份 markdown 是由官方原檔轉出，轉出後逐項與原檔核對過。查核表 markdown 的末尾附註記錄了一件事：官方查核表只涵蓋公告「壹」十九點中的十點、「貳」十五項中的十三項，兩份文件的項目編號因此對不起來。這是官方文件的原貌，轉檔時照實保留，沒有自行補項。

## 項次格式

查核表表格的第一欄是項次，程式會解析它來檢查 AI 有沒有漏判（見 `src/lib/ai/checklist.ts`）。格式只接受兩種：

1. 應記載事項：數字，可帶子項，例如 `1`、`2-1`、`10-4`。
2. 不得記載事項：`B-` 開頭加數字，例如 `B-1`、`B-13`。

在後台更新查核表時若改動了這一欄的格式，漏判偵測會失效。目前這份共 32 個項次。
