## 壹、應記載事項

| 序號 | 查核項目 | 查核項目說明 | 判定選項 |
|---|---|---|---|
| 1 | 一、契約審閱期間 | 簽約前，至少三日之審閱期間。 | 符合／不符合 |
| 2-1 | 二、會員權利義務之說明 | (一) 應於訂約前交付消費者審閱會員規約。 | 符合／不符合／不適用 |
| 2-2 | 二、會員權利義務之說明 | (二) 業者應就會員種類及會員資格之權利義務，訂約前為詳細明確之口頭說明，提供與口頭說明內容相同之書面文件，並經消費者簽名確認。 | 符合／不符合／不適用 |
| 3 | 三、服務內容之說明義務 | 媒合交友與附加服務項目之內容、數量及價格，於訂約前為詳細明確之口頭說明，並於簽約時完整提供與口頭說明內容相同之書面文件，作為契約內容。 | 符合／不符合 |
| 4-1 | 四、提供之服務項目 | 契約起訖時間，載明下列服務項目：(一) 媒合交友：1. 約會對象、2. 排約方式、3. 排約時間。 | 符合／不符合 |
| 4-2 | 四、提供之服務項目 | (二) 附加服務（限諮商（諮詢）服務、實體課程、影音課程及書籍教材等 4 項）。查核重點：詳列內容及數量。 | 符合／不符合 |
| 4-3 | 四、提供之服務項目 | 業者已提供符合消費者要求條件之對象，消費者對於不同對象拒絕排約或未予回覆，至少三次以上，視同業者已完成一次排約。 | 符合／不符合 |
| 5-1 | 五、影音課程與書籍教材之使用及計費 | 影音課程、書籍教材屬非以有形媒介提供之數位內容者，載明：(一) 課程總時數及計費方式；(二) 消費者已使用時數或次數。消費者於契約生效後至少七日未下載、未登錄或登錄後未使用，並通知業者註銷使用帳號時，業者應退還全額費用。 | 符合／不符合／不適用 |
| 5-2 | 五、影音課程與書籍教材之使用及計費 | 影音課程、書籍教材屬光碟或其他有形商品者，業者有無密封包裝；不得以任何理由要求或協助消費者拆封。消費者未拆封，且於契約生效後至少七日將商品退還業者時，業者應退還全額費用。 | 符合／不符合／不適用 |
| 5-3 | 五、影音課程與書籍教材之使用及計費 | 消費者完全未使用影音課程、書籍教材，逾前二項期間，於契約存續期間內，通知業者註銷使用帳號或退還商品，業者應依下列方式計算退還消費者之費用（四捨五入計算至整數）：影音課程、書籍教材費用 × 契約未到期日數 ÷ 契約總日數。 | 符合／不符合／不適用 |
| 6 | 六、契約總費用 | 契約費用如下：入會費（不得逾契約總費用之百分之五）、媒合交友計價方式、附加服務費用、總費用。 | 符合／不符合 |
| 7 | 七、付費方式 | 有無載明：一次全部繳納；分期付款方式繳納；消費者與第三人訂立消費借貸契約方式繳納。 | 符合／不符合 |
| 8-1 | 八、業者轉介貸款機構 | 消費借貸契約應明列貸款機構、總金額、期數及月付數額。 | 符合／不符合／不適用 |
| 8-2 | 八、業者轉介貸款機構 | 業者提供消費者與第三人之貸款機構訂立消費借貸契約者，依應記載事項第十點第二項第一款至第八款規定，載明各相關約定告知消費者，並取得消費者聲明已受告知之證明文件。 | 符合／不符合／不適用 |
| 9 | 九、業者之履約保障責任 | 契約總費用預付金額超過五萬元者，應就超過金額部分提供履約保障，以下列方式擇一載明於契約明顯處：金融機構保證；信託專戶；金融機構開立價金保管專戶；同業同級相互連帶保證；交友媒合服務聯合連帶保證協定。（依提供履約保障方式勾選） | 符合／不符合／不適用 |
| 10-1 | 十、契約終止及退費 | 消費者於契約期間屆滿前，得隨時通知業者終止契約，業者不得拒絕。 | 符合／不符合 |
| 10-2 | 十、契約終止及退費 | 消費者通知業者終止契約，業者應於終止日後不得逾三十日退還費用予消費者；如有不足，得向消費者收取之。 | 符合／不符合 |
| 10-3 | 十、契約終止及退費 | (一) 契約生效七日內且消費者尚未接受服務而終止契約者，業者應全額退還已繳費用（指契約總費用）。 | 符合／不符合 |
| 10-4 | 十、契約終止及退費 | (二) 契約生效七日後或消費者已接受服務而終止契約者：1. 將已繳全部費用扣除已接受服務之費用，並扣除經消費者簽名確認已使用或已拆封之影音課程、書籍教材金額後退還於消費者。2. 前目已接受服務之費用計算方式如下：(1) 依簽約時每期／次使用費用乘以實際使用期／次；(2) 無法認定簽約時每期／次使用費者，按已接受服務期間占契約存續期間比例計算之費用。3. 入會費得不列入退費計算之範圍。4. 手續費之收取：不收取；或本契約總費用扣除已接受服務之費用，並扣除經消費者簽名確認已使用或已拆封之影音課程、書籍教材金額後剩餘金額之百分比，不得超過該剩餘金額之百分之十。 | 符合／不符合 |

## 貳、不得記載事項

| 序號 | 查核項目說明 | 判定選項 |
|---|---|---|
| B-1 | 一、不得記載消費者抛棄契約審閱期間及審閱權利。 | 符合／不符合 |
| B-2 | 二、不得記載消費者違反本契約時，消費者應抛棄已支付之費用。 | 符合／不符合 |
| B-3 | 三、不得記載消費者一經享受契約權利，即不得要求退費。 | 符合／不符合 |
| B-4 | 四、不得記載業者得保管或收回消費者持有之契約或類此字樣。 | 符合／不符合 |
| B-5 | 五、不得記載業者於訂約後得片面變更契約內容及會員規約。 | 符合／不符合 |
| B-6 | 六、不得記載廣告不構成契約內容或廣告僅供參考之文字。 | 符合／不符合 |
| B-7 | 七、不得於本契約或廣告記載「終身」、「永久」等用語或類此字樣。 | 符合／不符合 |
| B-8 | 八、不得記載消費者未於一定期限接受本服務時，即不得再行接受。 | 符合／不符合 |
| B-9 | 九、不得記載業者得以自動續約方式延長契約。 | 符合／不符合 |
| B-10 | 十、不得記載業者得將本契約債權讓與第三人。 | 符合／不符合 |
| B-11 | 十一、不得增列應記載事項規定以外之退費方式、違約金之收取或類此字樣。 | 符合／不符合 |
| B-12 | 十二、不得記載消費者提供票據作為擔保。 | 符合／不符合 |
| B-13 | 十三、業者之贈與不得記載附負擔。 | 符合／不符合 |

## 附註：查核表與公告全文的對應差異（轉檔時核對）

1. 查核表「壹」只列出公告「壹、應記載事項」十九點中的十點（審閱期間、會員權利義務、服務說明義務、服務項目、影音教材、總費用、付費方式、轉介貸款、履約保障、終止退費）。公告的第二點（當事人資料）、第八點（贈品約款）、第十二點（建檔紀錄）、第十三至十五點（各類終止事由與效果）、第十七點（催繳通知）、第十八點（個資保護）、第十九點（訴訟管轄）不在查核表內。
2. 查核表「貳」列出十三項，公告「貳、不得記載事項」有十五項。查核表未納入公告第四項（不得免除或限制業者依消保法、民法所負責任）與第十三項（不得記載違反強制禁止規定、公序良俗、誠信原則之顯失公平條款）；其餘十三項編號因此與公告不一致（查核表第四項起對應公告第五項起）。
3. 上述差異是官方兩份文件的原貌，本檔照實轉錄，未自行補項。
