# 交友合約健檢

檢查「交友媒合服務定型化契約」是否符合主管機關規定的網頁工具。

把契約放進來（照片、PDF、Word、Excel，或直接貼上條文），系統依
**縣市年交友媒合服務定型化契約查核表**逐條比對，列出不符合的條款與該怎麼改。

由 [霍家私塾](https://huobest.com/) 開發，免費開放，原始碼以 MIT 授權釋出。

若契約內容屬於不得外傳的資料，請把 AI 服務指向你機房內自架的模型。

## 自行部署

需要 Docker 與 Docker Compose。

```bash
git clone <這個倉庫的網址> dating-contract-checker
cd dating-contract-checker
cp .env.example .env
```

編輯 `.env`，至少要填這幾項：

| 變數 | 說明 |
|---|---|
| `PUBLIC_HOST` | 對外網域，例如 `contract.example.gov.tw` |
| `POSTGRES_PASSWORD` | 自訂的資料庫密碼，同時要填進 `DATABASE_URL` |
| `APP_ENCRYPTION_KEY` | `openssl rand -base64 32` 產生。用來加密資料庫內的 AI 金鑰 |
| `AUTH_SECRET` | `openssl rand -base64 32` 產生 |
| `AUTH_GOOGLE_ID`／`AUTH_GOOGLE_SECRET` | Google OAuth 用戶端，後台登入用 |
| `ADMIN_EMAILS` | 後台白名單信箱，逗號分隔。**不填的話沒有人能登入後台** |
| `TRUSTED_PROXY` | 依你的架構設為 `cloudflare`、`nginx` 或 `none` |

然後啟動：

```bash
docker compose up -d
```

首次啟動會自動建立資料表，並匯入查核表、公告全文、隱私權政策、服務條款
四份初始文件。服務跑在 `127.0.0.1:3400`，前面請自行架反向代理與 HTTPS。

### `TRUSTED_PROXY` 一定要設對

這個設定決定系統從哪裡取得使用者的真實 IP，而防濫用機制（速率限制、暫停、
封鎖）全都依賴 IP。

| 值 | 用在什麼架構 |
|---|---|
| `cloudflare` | 前面有 Cloudflare 代理。只認 Cloudflare 覆寫的 `CF-Connecting-IP` |
| `nginx` | 只有自架的反向代理，沒有 Cloudflare。取轉發標頭最右邊那一段 |
| `none` | 沒有任何代理（開發環境）。完全忽略轉發標頭 |

**設錯的後果**：填了 `cloudflare` 或 `nginx` 但前面其實沒有那層代理時，
任何人都能自己偽造標頭來假裝成別的 IP，防濫用等於失效。不確定就先用 `none`
再依實際架構調整。

## 啟動後要做的第一件事

登入 `https://你的網域/admincenter`，到「AI 設定」填入 AI 服務。

**這一版沒有預設的 AI 服務位址**，不填就不能分析。原始碼裡沒有寫死任何網域，
你填什麼就送到哪裡。

支援兩種供應商，可以只用一種，也可以兩種都填當作互相備援：

| 供應商 | 說明 |
|---|---|
| AI 閘道 | 任何相容 OpenAI 格式的端點。可以是商用服務，也可以是你機房內自架的模型 |
| Groq | 直連 Groq。支援多支金鑰輪替，純文字分析會優先走這裡 |

有文字層的 PDF、Word、Excel 都算純文字——系統會先把文字抽出來再送。
只有照片和沒有文字層的掃描檔需要視覺模型。

同一頁還有「濫用規則」與「保留期」可以調整，包括原始檔與分析結果各要留幾天。

## 法規文件怎麼更新

後台的「法規文件」頁管理四份文件：查核表、公告全文、隱私權政策、服務條款。

分析的依據是**查核表**。主管機關修訂查核表時，把新版內容貼進去、填上官方的
版本號與生效日期，按「發布為生效版本」即可。舊版本會保留，隨時可以回看。

版本號填已存在的號碼就是覆蓋那一版——版本號應該跟著官方走，不是系統流水號。

## 這套系統做什麼、不做什麼

**做**：依查核表逐項比對，列出符合、不符合、建議修正、不適用四種判定，
只有不符合與建議修正才給改善方式。

**不做**：它不是主管機關的查核結果，也不構成法律意見。判定由 AI 產生，
一切以主管機關公告的內容及其認定為準。這段話也寫在前台的使用說明裡。

系統會拒絕交友媒合服務契約以外的文件。判定不確定時一律放行，寧可放過不相關
的文件，也不誤擋真實的使用者；這個行為可以在後台關閉。

## 技術

Next.js 16、React 19、TypeScript、PostgreSQL 16、Drizzle ORM、Tailwind CSS 4。

PDF 解析用純 JavaScript 的 pdfjs 搭配 `@napi-rs/canvas`，不需要在主機上安裝
poppler 之類的系統套件。

```
src/
├── app/          頁面與 API
├── components/   共用元件
├── lib/
│   ├── ai/       AI 備援鏈、提示詞、查核表比對、文件類型判定
│   ├── extract/  PDF、Word、Excel、影像的文字抽取
│   ├── guard/    IP 狀態、每日配額、速率限制
│   └── email/    問題回報的回覆通知
└── db/           資料表定義與遷移
```
